Claude Code Plugin

Coding lessons that run inside Claude Code — and ship verified work.

ACC turns a Claude Code session into an interactive coding tutor. You install the framework, you install (or write) a course plugin, and the conductor walks the learner section by section — advancing an HTML artifact, gating on real test runs, and adapting to the chosen output mode.

How it works

ACC is the engine. Courses are content plugins. Lessons are the experience — reference-seeded, test-verified, and packaged as a shareable HTML artifact at the end.

Three pieces, clearly separated

ACC ships no lesson content of its own. That separation is the design — the framework stays small and reusable; courses own their domain.

Framework

ACC

This plugin. MCP server, conductor agent, authoring skills, the four probe interpreters, and the workspace lifecycle. Domain-agnostic.

Content

Course plugin

A separate Claude Code plugin that declares accContent — lessons, prerequisite probes, configurable paths. ACC discovers it at runtime.

Experience

Lesson

An end-to-end run: pick output mode, walk the section sequence, advance the HTML artifact, pass a final test gate, publish the result.

Two output modes — one lesson

The learner picks how active they want to be. The same lesson runs either way; only the conductor's behaviour changes.

Learning mode

For learners who want to write the code.

  • Conductor leaves TODO markers at the key moments of each section
  • Learner fills in the implementation; the conductor reviews
  • Verification still has to pass before the section advances

Explanatory mode

For learners who want a guided demo.

  • Conductor implements and narrates each step
  • Learner watches, asks questions, runs the final result
  • Same artifact, same verification gates

Quick start

ACC is a Claude Code plugin. Install it, install a course alongside it, and start a lesson.

1

Install ACC

From any Claude Code session:

/plugin marketplace add contract-hero/plugin-marketplace
/plugin install agentic-community-college@contract-hero
2

Install a course

Any plugin that declares accContent works. The reference course is acc-deepbook-course.

/plugin install acc-deepbook-course@contract-hero
3

Start a lesson

Run the course's start command. ACC discovers the catalog, you pick a lesson, the conductor takes over.

/acc-deepbook-course:start
4

Author your own

To teach a new domain, scaffold a course plugin and add lessons:

/agentic-community-college:create-course
/agentic-community-college:create-lesson
Note. ACC pairs with the toolkit@contract-hero plugin for HTML-deliverable skills (per-section diagrams, post-lesson publishing). It's optional — lessons still run without it, just without the visual extras.
